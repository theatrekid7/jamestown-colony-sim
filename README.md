# Jamestown 1607: The Chesapeake

A browser-based historical strategy prototype set in 1607. You play as Captain John Smith, leading the Jamestown colony through food shortages, diplomacy, trade, and political tensions with the Powhatan polity.

## Features

- Playable isometric map of the Chesapeake region
- Movement with WASD or arrow keys
- Resource gathering and colony management
- NPC interactions with historical figures
- Powhatan diplomacy and trade system
- Survival, morale, trust, and political pressure mechanics
- Seasonal progression and win/lose conditions

## How to run

1. Download or clone the repository.
2. Open `index.html` directly in a browser.
3. Use the keyboard to move and interact.

## Controls

- Move: W, A, S, D or Arrow Keys
- Interact with nearest figure: E
- Advance season: Space or the "Next Season" button
- Buttons on the right side handle activities like gathering, trading, fortifying, and mapping.

## Notes

This is a prototype designed around historical themes and interactive survival. It is intentionally simplified for a browser demo and is meant to be built upon further with richer quests, more story branches, and expanded systems.
